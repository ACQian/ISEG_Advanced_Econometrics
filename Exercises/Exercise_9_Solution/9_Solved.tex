    Obtain the 95\% confidence interval for the \textbf{mean} of lhhexp1 using:\\

    \textbf{i. Standard asymptotic theory}\\

    \textcolor{Magenta}{ci means lhhexp1}\\

    The 95\% confidence interval is [9.324154, 9.358968]\\

    \textbf{ii. Standard asymptotic theory using the boostrap mean and the boostrap standard errors}\\

    \solution\\

    \textcolor{Magenta}{bootstrap r(mean), reps(499): sum lhhexp1}\\
    First generate bootstrap sample with 499 repetitions at the mean then showing the summary.\\
    \includegraphics[scale=0.7]{Image_9/3.png}\\
    The 95\% confidence interval is [9.324018, 9.359105].\\

    \textbf{iii. The boostrap percentile method}\\

    \solution\\

    \textcolor{Magenta}{estat bootstrap, all}\\
    This is asking STATA to show the information of all bootstrap confidence interval construction methods.
    The middle line is the bootstrap confidence interval using the percentile method.\\
    \includegraphics[scale=0.7]{Image_9/4.png}\\
    The 95\% confidence interval is [9.32274, 9.359476]\\

    \textbf{iv. The boostrap t-statistics with both methods}\\

    \solution\\

    Minimizing $S(b) = \frac{1}{N}\sum_{i=1}^{N}(Y-b)^2 \rightarrow$ taking the derivative and setting to zero
    \begin{gather*}
        \frac{2}{N}\sum_{i=1}^{N}(Y_i-\hat{b})=0\\
        \frac{2}{N}\sum_{i=1}^{N}Y_i - \frac{2}{N}\sum_{i=1}^{N}\hat{b} = 0\\
        \frac{2}{N}\sum_{i=1}^{N}Y_i - \frac{2}{N}N\hat{b} = 0\\
        2\hat{b} = 2\frac{1}{N}\sum_{i=1}^{N}Y_i\\
        \hat{b} = \frac{1}{N}\sum_{i=1}^{N}Y_i
    \end{gather*}
    which is just the sample mean.
    \textcolor{Magenta}{\begin{enumerate}
        \item bootstrap "regress lhhexp1" \_b \_se, reps(499) saving(bsdata)\\
            \includegraphics[scale=0.6]{Image_9/5.png}
        \item regress lhhexp1\\
            \includegraphics[scale=0.6]{Image_9/6.png}
        \item Now use the saved boostrap dataset to continue, in this case, bsdata.dta
    \end{enumerate}}

    The first method is the \textbf{non-symmetric test} with the critical values of 
    $cv_{boot}(\frac{\alpha}{2})$ and $cv_{boot}(1-\frac{\alpha}{2})$ for $(\hat{t}_1,\ldots,\hat{t}_B)$.
    \textcolor{Magenta}{
        \begin{enumerate}
            \item gen double t\_cons = ( b\_cons-\_b[\_cons])/ se\_cons
            \item \_pctile t\_cons, percentiles(2.5 97.5)
            \item display \_b[\_cons]-\_se[\_cons]*r(r2)
            \item display \_b[\_cons]-\_se[\_cons]*r(r1)
        \end{enumerate}}
    The result gives the 95\% confidence interval of [9.3238664, 9.3603002].\\ 

    The second method is the \textbf{symmetric test} with the critical value of $cv_{boot}^a(1-\alpha)$
    for $(|\hat{t}_1|,\ldots,|\hat{t}_B|)$.
    \textcolor{Magenta}{
        \begin{enumerate}
            \item gen double at\_cons=abs( t\_cons )
            \item \_pctile at\_cons, percentiles(95)
            \item display \_b[\_cons]-\_se[\_cons]*r(r1)
            \item display \_b[\_cons]+\_se[\_cons]*r(r1)
        \end{enumerate}}
    The result gives the 95\% confidence interval of [9.3229329, 9.3601895].\\ 

\end{homeworkProblem}

\begin{homeworkProblem}
    
    Suppose $X_1,\ldots, X_n$ are i.i.d. continuous r.v. from distribution with cumulative distribution function
    $F_X(\cdot)$ and probability density function $f_X(\cdot)$. Let $M_n$ be the \textbf{sample median} and $m_0$
    be the \textbf{population median}. 
    In this case $\displaystyle\sqrt{n}(M_n-m_0)\xrightarrow{d} N\left(0,\frac{1}{4(f_X(m_0))^2}\right)$.\\

    \textbf{i. Propose a consistent estimator for the asymptotic variance of $\sqrt{n}(M_n-m_0)$}\\

    \solution\\

    A consistent estimator for the density is $\displaystyle\frac{1}{4\hat{f}_x^2(M_N)}$ 
    where $\displaystyle\hat{f}_x(M_N) = \frac{1}{Nh}\sum_{i=1}^{N}K\left(\frac{y_i-M_N}{h}\right)$,
    a kernal density estimator.\\

    \textbf{ii. Obtain a 95\% CI for the median of lhhexp1}\\

    \textbf{A. using standard asymptotic theory with the consistent estimator proposed previously}\\

    \solution\\

    $SE(M_N) = \frac{1}{\sqrt{n}\sqrt{4f_X^2(M_N)}}$\\

    $(M_N - Z_{\frac{\alpha}{2}}\,SE(M_N), \,M_N + Z_{\frac{\alpha}{2}}\,SE(M_N))$\\

    $P(Z>Z_{\frac{\alpha}{2}}) = \frac{\alpha}{2},\,Z\sim N(0,1)$\\

    $h = 0.09904 \to$ obtained from Exercise sheet 8 with \textbf{Silverman's rule of thumb}\\

    Steps to do:
    \begin{enumerate}
        \item Find the median
        \item Generate the sequence
        \item Find the mean of sequence
    \end{enumerate}
    \textcolor{Magenta}{
        \begin{enumerate}
            \item \textcolor{Black}{Do not forget to clear the dataset first as in to reload the original dataset}
            \item sum lhhexp1, d\\
                \includegraphics[scale=0.7]{Image_9/7.png}
            \item gen double a = normalden(( lhhexp1 -9.311416)/0.09904)/0.09904
            \item mean a\\
                \includegraphics[scale=0.7]{Image_9/8.png}
            \item display (1/(2*.6392072*sqrt(5999))) \textcolor{Black}{to get $SE(M_N)$}
            \item display 9.311416-1.96*0.01009925 \textcolor{Black}{to get lower bound of CI}
            \item display 9.311416+1.96*0.01009925 \textcolor{Black}{to get upper bound of CI}
        \end{enumerate}}
    The 95\% confidence interval is [9.2916215, 9.3312105]\\

    \textbf{B. using standard asymptotic theory with the bootstrap mean and bootstrap standard error}\\

    \solution\\

    \textcolor{Magenta}{bootstrap r(p50), reps(499): sum lhhexp1, d}\\

\begin{homeworkProblem}
    Obtain a 95\% confidence interval for $\beta_2$ using\\

    \textbf{i. Standard asymptotic theory with robust standard errors}\\

    \solution\\

    We first need to generate the squares then run the regression using robust standard error. 
    \textcolor{Magenta}{
        \begin{itemize}
            \item gen age2= age\^2
            \item reg lnrlfood lhhexp1 age age2, r
        \end{itemize}
    }
    \includegraphics[scale=0.7]{Image_9/11.png}\\
    The 95\% confidence interval with robust standard error considering heteroskedasticity is [0.6830901, 0.7054815]\\

    \textbf{ii. Standard asymptotic theory using bootstrap mean and boostrap standard errors}\\

    \solution\\

    Now we need to use bootstrap of the pairs to answer the rest of the questions.
    \textcolor{Magenta}{
        \begin{itemize}
            \item bootstrap "reg lnrlfood lhhexp1 age age2, r" \_b \_se, reps(499) dots saving(bsdata2)
        \end{itemize}
    }
    \includegraphics[scale=0.7]{Image_9/12.png}\\

    We are interested in the first variable b\_lhhexp1 and its confidence intervals.
    The 95\% confidence interval using the boostrap mean and bootstrap standard error is [0.6837384, 0.7048333].\\

    \textbf{iii. The bootstrap percentile method based on the boostrap of the pairs}\\

    \solution\\

    Referring again to the previous bootstrap results.
    The 95\% confidence interval using the boostrap percentile method is given by [0.6831305, 0.7036634].\\

    \textbf{iv. The boostrap t-statistics based on the boostrap of the pairs with both methods}\\

    \solution\\

    We now need to compute the bootstrap t-statistics using the saved database bsdata2 done in step ii.\\

    First using the non-symmetric method:
    \textcolor{Magenta}{
        \begin{itemize}
            \item reg lnrlfood lhhexp1 age age2, r\\
                \includegraphics[scale=0.7]{Image_9/13.png}
            \item import saved database
            \item gen t\_lhhexp1=( b\_lhhexp1- \_b[lhhexp1])/ se\_lhhexp1
            \item \_pctile t\_lhhexp1, p(2.5, 97.5)
            \item dis \_b[lhhexp1]-\_se[lhhexp1]*r(r2) \textcolor{Black}{Lower bound}
            \item dis \_b[lhhexp1]-\_se[lhhexp1]*r(r1) \textcolor{Black}{Upper bound}
        \end{itemize}
    }
    The 95\% confidence interval using the bootstrap t-statistics with non-symmetric method is given by [0.68455932, 0.70538].\\

    Then using the symmetric method:
    \textcolor{Magenta}{
        \begin{itemize}
            \item gen at\_lhhexp1=abs( t\_lhhexp1)
            \item \_pctile at\_lhhexp1, p(95)
            \item dis \_b[lhhexp1]-\_se[lhhexp1]*r(r1) \textcolor{Black}{Lower bound}
            \item dis \_b[lhhexp1]+\_se[lhhexp1]*r(r1) \textcolor{Black}{Upper bound}
        \end{itemize}
    }
    The 95\% confidence interval using the bootstrap t-statistics with symmetric method (absolute value) is given by [0.68374724, 0.70482441].

\end{homeworkProblem}
